# Smart-Relay-IoT
An end-to-end IoT smart solution utilizing an Android app to remotely control and monitor physical hardware appliances via ESP32 and lightweight MQTT communication protocols.


## Installation

### Run from source (Android Studio)
1. Clone the repo:
   
   ```
   https://github.com/elbehi-ahmed/IoT-Smart-Lighting-System.git
   ```
3. Open the project in **Android Studio** (Hedgehog or newer recommended).
4. Let Gradle sync finish.
5. Click **Run ▶** and select an emulator or a physical device .
