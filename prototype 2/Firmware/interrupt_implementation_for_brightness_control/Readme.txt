the architecture i implemented uses 3 interrupts , the first one is a pin interrupt that detects the zero crossing from my comparator&transformer circuit which triggers the fucntion zcfunction() and it also
that starts/arms another timer interrupt that waits for the correct firing time according to the desired brightness(there is a calibration table and a mapping of the values to make it as close to linear as it gets,using power approximation v^2/R)
the second timer interrupt we just talked about has its callback function calling turning on the triac via an optocoupler and arms the third timer interrupt with 75 micro secs(enough to fire the triac) then when this third interrupt triggers it just turns trhe optocoupler off that way every 0 crossing which is every 10 ms the cycle restarts
